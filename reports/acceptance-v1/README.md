# WCP 第一版验收产物

- `reports/product/`：产品经理角色验收报告
- `reports/engineering/`：技术人员角色验收报告
- `validation/acceptance-test-report-zh.md`：最终测试报告
- `validation/product-manager-review.md`：产品角色验收
- `validation/engineer-review.md`：工程角色验收
- `validation/metrics.json`：核心性能和覆盖指标
- `validation/provider-comparison.json`：CodeGraph 与 Source-only 对比
- `validation/report-quality.json`：报告结构和质量得分
- `validation/source-references.json`：报告源码路径/行号检查
- `validation/source-assertions.json`：75 条当前源码断言

本目录不包含 WCP 原始源码、环境变量或凭据。
